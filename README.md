# SPIM: A MIPS32 Simulator

This is a fork of the latest snapshot of SPIM (QtSpim 9.1.24/r764) by [Professor Emeritus James Larus](https://en.wikipedia.org/wiki/James_Larus), who no longer maintains it. The official project page [remains here on SourceForge](https://spimsimulator.sourceforge.net/).

The original README is [here](./README).

Documentation is [here](./Documentation), including this [appendix in Patterson and Hennessy](./Documentation/SourceForge/HP_AppA.pdf).

As a gentle tutorial, I enjoyed a [Programmed Introduction to MIPS Assembly Language](https://chortle.ccsu.edu/assemblytutorial/).

Many modern computer architecture courses use [RISC-V](https://riscv.org/).

Relevant courses at MIT:
- [6.1910: Computation Structures](https://6191.mit.edu/)
- [6.5900: Computer System Architecture](https://csg.csail.mit.edu/6.5900/)
- [6.1810: Operating System Engineering](https://pdos.csail.mit.edu/6.1810/)
